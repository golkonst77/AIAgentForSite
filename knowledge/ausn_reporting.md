# Порядок отчетности при АУСН

## Общие требования

При применении автоматизированной упрощенной системы налогообложения установлены специальные требования к отчетности, направленные на ее упрощение и автоматизацию.

## Виды отчетности

При АУСН необходимо представлять следующие виды отчетности:

1. Налоговая декларация по единому налогу
2. Отчет по страховым взносам
3. Бухгалтерская отчетность (упрощенная форма)
4. Статистическая отчетность

## Сроки представления отчетности

| Отчетность | Периодичность | Срок представления |
|------------|--------------|-------------------|
| Налоговая декларация | Ежеквартально | Не позднее 25 числа месяца, следующего за отчетным кварталом |
| Отчет по страховым взносам | Ежеквартально | Не позднее 30 числа месяца, следующего за отчетным кварталом |
| Бухгалтерская отчетность | Ежегодно | Не позднее 31 марта года, следующего за отчетным годом |
| Статистическая отчетность | Ежеквартально | Не позднее 20 числа месяца, следующего за отчетным кварталом |

## Форматы представления отчетности

Все отчеты при АУСН представляются в электронной форме через систему "Электронный налогоплательщик":

- Формат файлов: XML
- Подпись: Электронная цифровая подпись (ЭЦП)
- Канал передачи: Защищенное HTTPS-соединение
- Подтверждение получения: Автоматическое уведомление в личном кабинете

## Автоматизированный расчет налогов

Система АУСН предусматривает автоматизированный расчет налогов на основе данных, введенных в учетную систему:

1. Ввод первичных документов
2. Автоматический расчет налоговой базы
3. Формирование налоговой декларации
4. Проверка на ошибки
5. Подписание ЭЦП
6. Отправка в налоговый орган

## Контрольные соотношения

При автоматическом формировании отчетности система проверяет следующие контрольные соотношения:

- Соответствие выручки и расходов
- Правильность применения налоговых ставок
- Своевременность уплаты налогов
- Полное отражение всех операций

## Ответственность за нарушение отчетности

За нарушение порядка отчетности при АУСН предусмотрена ответственность:

- Пени за несвоевременную уплату налогов
- Штрафы за непредставление или несвоевременное представление отчетности
- Блокировка личного кабинета при систематических нарушениях
- Прекращение применения АУСН при грубых нарушениях

## Поддержка и консультации

Для получения консультаций по вопросам отчетности при АУСН можно обратиться:

- В личный кабинет налогоплательщика (онлайн-чат)
- По телефону горячей линии: 8-800-123-45-67
- В налоговые инспекции по месту учета
- Через официальный сайт ФНС России
